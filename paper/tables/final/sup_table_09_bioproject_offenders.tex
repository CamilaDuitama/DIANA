{\footnotesize \textbf{Columns}: \textit{BioProject}---NCBI BioProject accession. \textit{Study}---first-author and year of the associated publication. \textit{Train/Test/Val err.}---number of wrong predictions (across all four tasks) in each dataset split; `{--}' means the BioProject has no samples in that split. \textit{Total}---sum of wrong predictions across all three splits. $^{a}$~\textit{Err.\,(\%)}: wrong predictions as a percentage of all predictions made for that BioProject (each sample contributes four predictions, one per task). $^{b}$~\textit{Cum.\,(\%)}: running total of errors as a percentage of all errors across every qualifying BioProject ($\geq$5 samples in test + validation); shows how concentrated errors are in a few studies. $^{c}$~\textit{Error type}: four categories are used. \textit{Absent class}: the true label never appeared in training. \textit{Label granularity}: the true label is absent from training but is a biological subtype of a training class (e.g.\ \texttt{lake sediment} $\subset$ \texttt{sediment}); the model predicts the correct coarser label. \textit{Taxonomic granularity}: the true host is a subspecies whose parent taxon is the training label (e.g.\ \textit{Gorilla beringei beringei} $\to$ \textit{Gorilla}~sp.\ in training). \textit{Genuine confusion}: all true labels were seen in training; the model still predicts the wrong class. $^{d}$~\textit{Main errors}: top true\,$\to$\,predicted label pairs by frequency. Task abbreviations: ST\,=\,Sample Type, CT\,=\,Community Type, SH\,=\,Sample Host, Mat.\,=\,Material.}
